# Changelog

## 2026-09-08

- یکپارچه‌سازی Tailwind CSS (v4) در `@art-news/web` در کنار فونت وزیرمتن و متغیرهای رنگی پروژه.
- پیاده‌سازی هدر Mobile-first با نشان رسمی «سینما نمایش»، نوار تاریخ و نسخه، و ساختار کاملاً واکنشی.
- پیاده‌سازی کامپوننت جست‌وجوی بازشونده موبایل (`MobileSearch`) با انیمیشن نرم در همان نما، فوکوس خودکار، کلید Escape، دکمه انصراف و هدایت به صفحه نتایج جست‌وجو.
- بازطراحی منوی همبرگری کشویی (`NavigationMenu`) با چیدمان دقیق شامل صفحه نخست، زیرمنوی سینما (گفت‌وگو، نمایش، خبر و نقد و یادداشت)، تئاتر، تلویزیون، شبکه نمایش خانگی، سینمای جهان، عکس، فیلم، English و درباره ما.
- بسته‌شدن خودکار منو با کلیک بیرون، فشردن Escape، یا کلیک روی هر لینک با مدیریت focus و ARIA مناسب.
- پیاده‌سازی صفحه جامع «درباره ما» (`/about`) شامل اهداف و ماموریت، شفافیت و استانداردهای تحریریه، گواهی رسمی رسانه و بخش شبکه‌های اجتماعی (لینک فعال اینستاگرام و جایگاه‌های در حال راه‌اندازی تلگرام، یوتیوب و بله).

## 2026-09-06

- تثبیت پورت پیش‌فرض Next.js روی `3001` برای اجرای development و production
  محلی.
- انتقال پورت پیش‌فرض NestJS API به `4001` و هماهنگ‌سازی CORS با frontend روی
  `http://localhost:3001`.
- هماهنگ‌سازی API rewrite، metadata base، فایل‌های env نمونه و مستندات اجرای
  محلی با پورت‌های جدید.

## 2026-09-04

- اضافه‌شدن لوگوی تأییدشده «سینما نمایش» به‌صورت PNG محلی و جایگزینی نشان متنی
  قبلی در هدر دسکتاپ و موبایل.
- اضافه‌شدن لینک مستقیم مجوز پایگاه خبری با گواهی `101661` به فوتر.
- اضافه‌شدن Client Component مهر رسمی رسانه با بارگذاری async اسکریپت رسمی
  `trustseal.e-rasaneh.ir`.
- به‌روزرسانی متن معرفی فوتر با اشاره به سابقه فعالیت رسانه با نام اکران نیوز و
  نمایش دامنه اصلی `cinemanamayesh.ir`.

## 2026-09-02

- تغییر نام عمومی سایت از «هنرنامه» به «سینما نمایش» در رابط، metadata،
  structured data، نام تحریریه و کارت Open Graph.
- بازنویسی دسته‌بندی‌ها، خبرهای نمونه، متن رابط و metadata برای رسانه تخصصی
  سینما و نمایش.
- اضافه‌شدن منوی همبرگری مشترک موبایل و دسکتاپ با زیرمنوی سینما، مدیریت focus،
  قفل scroll و بسته‌شدن با کلیک بیرون، Escape یا انتخاب لینک.
- اضافه‌شدن Placeholder مشترک اکران نیوز و تبلیغات به صفحه اصلی، دسته‌بندی و
  جزئیات خبر.
- اضافه‌شدن صفحه‌های نمایشی `English` و «درباره ما» برای جلوگیری از لینک منوی
  بدون مقصد.
- به‌روزرسانی شعار کارت Open Graph به «رسانه سینما و نمایش».

  تولیدشده با هوش مصنوعی.
